==========================================================================
COMO FAZER UM "DUMP", OU SEJA, UM BACKUP DO ESTADO ATUAL DA BASE DE DADOS?
==========================================================================

- Acesse o terminal e execute o seguinte comando abaixo. Este comando irá exportar um script ".sql" contendo toda a estrutura atual da base de dados e compatível com a versão do PostgreSQL instalada no container (16) para o diretório compartilhado "/shared".

docker exec -t tp-db /usr/lib/postgresql/16/bin/pg_dump -U postgres -d protheus -F p --inserts --no-owner --no-privileges -f /shared/dump_protheus.sql
